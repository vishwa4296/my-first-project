# AI Career Guidance Website (BCA Final Year)

This is a simple **order-wise website** project for BCA final year:

1. **Login** (Step 1)
2. **Enter career + skills** (Step 2)
3. **View AI skill-gap report** (Step 3)

## Features
- Step-by-step student flow (login → skills → report)
- Career-wise skill gap analysis
- 30/60/90 day learning roadmap
- Suggested course resources for missing skills
- Logout and restart flow

## Tech Stack
- Python Flask
- HTML + CSS
- Session-based flow (for demo)

## Run Locally
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open: `http://127.0.0.1:5000`
